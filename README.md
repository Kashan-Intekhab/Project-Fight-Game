# 🥊 2D Python Fighting Game

A classic 2D fighting game built from scratch using Python and Pygame. This project focuses on core game development principles, including state management, custom physics, animated sprites, and precise combat collision detection.

---

## 🚀 Features

* **Responsive Controls:** Smooth left/right movement, jumping, and gravity physics.
* **Sprite Animations:** Dynamic animations for idle, running, jumping, attacking, and taking damage.
* **Combat System:** Accurate **Hitbox** and **Hurtbox** collision detection for attacks and damage rendering.
* **UI & Audio:** Real-time health bars, round timers, game states, and immersive sound effects.

---

## 🛠️ Built With

* **Language:** [Python 3.x](https://www.python.org/)
* **Game Engine / Library:** [Pygame](https://www.pygame.org/)
